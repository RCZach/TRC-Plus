GAME CONNECTION
Connect your game roster.
Start NBA 2K27 and load your roster. This editor connects directly to the running game. Select Check game connection, then Load game roster.
Import your TRC export and choose Merge to match unique player names while keeping game record IDs. Start live editing once, then supported field changes apply automatically after a short pause, Enter, or leaving the field. Undo game edit and Redo restore session edits. JSON imports still use Preview bulk changes. Save JSON workspace saves a local copy; save the roster inside NBA 2K27 to keep game edits.
Starting live editing enables writes for the loaded game session without manually entering a build. The settings below optionally enable bulk writes by default. Named values need an observation for this build; use Learn name next to a mapped field. Raw Advanced entries and team mappings remain local.
Saving connection settings requires reloading the game roster.
Empty fields are unknown values, not zeroes. Set a value to add it to your roster document.

LEARN A GAME VALUE
Open this exact player and field in 2K. Enter the name currently displayed there. The editor will read its current game ID and remember the pair for this build; this does not change the game.


MAP A MISSING FIELD
Record one change in 2K.
Take a before snapshot, change only this field on this exact player in 2K, commit the edit there, then compare. This records evidence without changing game memory or automatically enabling unknown offsets.
