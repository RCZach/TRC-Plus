# TRACE 0.5.0 Beta

This is the 0.4.1 beta rebuilt with the new 0.5.0 version number. The app's
features and game mappings are the same as in 0.4.1.

- Sync from TRC matches players in the loaded game roster and reports progress
  while it works. The player list can show only matched TRC players.
- The sync preview includes only values supplied by TRC. NBA 2K25 badges are
  translated to the selected NBA 2K27 targets, and verified hot-zone names
  resolve on the supported game build.
- Coaching values and ratings with verified mappings can be edited with review,
  readback checks, and Undo/Redo.
- Unverified signature animation and accessory names remain excluded from game
  updates.

Extract the whole ZIP and run `TRACE.exe`. Beta updates are installed manually;
the in-app updater checks stable releases only.
