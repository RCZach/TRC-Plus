TRC+ now supports optional updates from GitHub Releases.

- Use **Check for updates** to see the newest version and release notes.
- Choose **Update and restart** when you are ready. Save your workspace first.
- Downloads are verified before installation. The previous app is retained as
  a backup, and your settings and roster files stay in place.
- Updates never install automatically.

If you are using 0.2.0 or earlier, extract this ZIP and launch TRC+.exe once.
Future updates can then be installed from inside the app. Keep the entire
extracted folder together, including TRC+ Updater.exe and _internal.
