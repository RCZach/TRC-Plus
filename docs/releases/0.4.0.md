# TRACE 0.4.0 Beta

This beta expands TRACE's roster editing and NBA 2K27 integration. It is for
64-bit Windows and supports live writes only for individually verified fields
on the supported game build. Other builds and unverified fields remain
read-only.

- Edit and review player and team roster data, then save a local JSON workspace
  or export a roster file.
- Import TRC JSON exports or sync pending TRC upgrades, preview the changes,
  and apply supported updates when ready.
- Connect to a running NBA 2K27 game to load a roster. Live editing is opt-in;
  bulk writes require review and support Undo/Redo.
- Browse additional verified player fields, Body values, gear, hot zones, and
  selected coaching defaults.
- Use the desktop app without installing Python or Cheat Engine.
- Fix startup when Windows marks bundled .NET files as downloaded from the internet.

To install, extract the entire ZIP and run `TRACE.exe`. Keep the `_internal`
folder beside it. Beta updates are manual: download and extract a newer beta
from GitHub Releases. The in-app updater checks stable releases only.

Please export a backup before editing a roster you care about. Save changes
inside NBA 2K27 to keep them in the game; saving a TRACE workspace only saves
the local JSON copy. See `START HERE.txt` in the ZIP for setup details.
