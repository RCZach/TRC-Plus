# TRACE 0.5.1 Beta

This update makes TRC sync easier to apply and improves matching for names
with multiple words or a suffix.

- **Sync from TRC** no longer requires **Start live editing**. Review the
  preview and choose **Apply to game** to authorize that batch only.
- Multiword names remain intact when matching the loaded roster to TRC.
  Optional suffix periods, such as `Zachary James Jr.` versus
  `Zachary James Jr`, are handled in the website lookup and merge.
- If a normalized name matches more than one game player, Trace still skips
  it and reports the ambiguity.

Extract the whole ZIP and run `TRACE.exe`. Beta updates are installed manually;
the in-app updater checks stable releases only. Save the roster inside NBA 2K27
after applying changes to keep them in the game.
