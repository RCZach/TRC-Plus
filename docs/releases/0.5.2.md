# TRACE 0.5.2 Beta

This update improves TRC player matching and corrects the supported-build
Passing Vision mapping.

- **Only show TRC players** and **Sync from TRC** now use the same server-side
  matching rules. Confirmed name aliases are supported, while duplicate or
  ambiguous names remain excluded.
- TRC exports using the confirmed spelling `Colton Fishcale Barkberg` now
  match the website player `Colton Fishscale Barkberg`.
- Passing Vision (also called Pass Vision in TRC exports) uses the corrected
  `0x46E` player-record byte and is writable only on build
  `6AD2E48C:36532000` through the reviewed, opt-in update path. Confirm it with
  one player in game before using it in a bulk update.

Extract the whole ZIP and run `TRACE.exe`. Beta updates are installed manually;
the in-app updater checks stable releases only. Save the roster inside NBA 2K27
after applying changes to keep them in the game.
